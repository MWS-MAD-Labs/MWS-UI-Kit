# MWS Heart & Purpose UI Kit

A warm, compassionate, school-ready UI kit for Millennia World School digital products developed by MAD Labs.

This repository is a living reference for apps such as:

- `reading-buddy`
- `mws-proofpoint`
- `mws-mtss-system`
- `mws-daily-checkin`
- future MWS/MAD Labs products

## Design direction

MWS interfaces should feel:

> Compassionate. Human-centered. Warm. Values-led. Joyful. Clear. Beautiful.

The system is based on the MWS message:

> Growing with Heart and Purpose.

- Vite
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Getting started

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Brand colors

| Color | Hex | Role |
| --- | --- | --- |
| MWS Burgundy | `#7E1518` | Primary identity, headers, main buttons |
| MWS White | `#FFFFFF` | Main background and readable space |
| Happiness Gold | `#D6A13A` | Highlights and joyful accents |
| Deep Charcoal | `#241718` | Main text instead of pure black |
| Compassion Rose | `#B94A4E` | SEL, kindness, wellbeing |
| Goodness Sage | `#6F8B6A` | Growth, sustainability, student support |
| Truth Navy | `#1F2A44` | Academics, evidence, trust |
| Millennia Sky | `#B8DDF8` | Calm, reflection, child-centered softness |

## Product color guidance

| Product context | Recommended palette |
| --- | --- |
| Reading / library | Burgundy + Gold + Sky |
| Wellbeing / check-in | Burgundy + Rose + Sky |
| MTSS / student support | Burgundy + Sage + Sky |
| Proofpoint / performance | Burgundy + Navy + Gold |
| Parent communication | Burgundy + White + Charcoal + small Gold accent |

## Design rule

Every MWS design should help people feel that MWS is a place where goodness grows.
